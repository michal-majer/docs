## What is S4Kit?

S4Kit is a developer-friendly SDK and platform that simplifies SAP S/4HANA integration. Instead of wrestling with complex SAP infrastructure, you get a clean TypeScript API with API key authentication—similar to working with Stripe.

## Quick Example

```typescript
import { S4Kit } from 's4kit';

const client = new S4Kit({
  apiKey: 'sk_live_...',
  connection: 'production'
});

// List business partners with filtering
const partners = await client.sap.A_BusinessPartner.list({
  select: ['BusinessPartner', 'BusinessPartnerName'],
  filter: "BusinessPartnerCategory eq '1'",
  top: 10
});

// Create a new sales order
const order = await client.sap.A_SalesOrder.create({
  SalesOrderType: 'OR',
  SoldToParty: '10100001',
  // ...
});
```

## Architecture Overview

```
┌─────────────┐     ┌──────────────┐     ┌─────────────┐
│   Your App  │────▶│  S4Kit Proxy │────▶│  SAP S/4    │
│  (SDK)      │◀────│  (Platform)  │◀────│  HANA       │
└─────────────┘     └──────────────┘     └─────────────┘
       │                    │
       │                    ▼
       │            ┌──────────────┐
       └───────────▶│   Dashboard  │
                    │  (Admin UI)  │
                    └──────────────┘
```

The platform acts as a secure proxy between your application and SAP systems, handling authentication, rate limiting, and access control.
